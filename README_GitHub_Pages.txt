SUNEETHA & MANOHAR — BRIDE-SIDE GITHUB PAGES WEBSITE

CONTENTS
- index.html: complete wedding invitation website
- 01.jpg to 05.jpg: the five selected wedding photos used in Our Moments
- visual-byte-logo.png: The Visual Byte footer logo
- music.mp3: invitation background music

PUBLISHING STEPS
1. Download this ZIP and extract it.
2. Open your GitHub repository for the invitation.
3. Upload the CONTENTS of the extracted folder to the repository root (not the ZIP file itself).
4. Replace the old index.html and old photo/music/logo files when prompted.
5. Commit the changes. In the repository, open Settings > Pages and ensure the publishing source is the branch/folder you use (commonly main / root).
6. Wait for deployment, then open your GitHub Pages URL and hard-refresh with Ctrl+F5.

IMPORTANT
Keep index.html, 01.jpg–05.jpg, visual-byte-logo.png, and music.mp3 together in the same repository root. Filenames are case-sensitive on GitHub Pages.

The HTML JavaScript syntax was checked before packaging. Live hosting and audio autoplay depend on browser/GitHub Pages settings; browsers may require a tap before music can play.
